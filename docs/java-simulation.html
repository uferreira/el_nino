Original Java Simulations

The original AWT programs are preserved and executed directly in your browser. Choose the theoretical double-well model or the January 2013 observational animation.

First load: the Java-compatible browser runtime is downloaded on demand and can take several seconds. It is cached for later visits. No Java installation or browser plugin is required.
